# Лабораторная работа №5
**Тема: Распознавание аудиосигналов и работа с одномерными данными.**

## Задачи

### 1. Классификация жанров музыки (Lite)
Провели исследование влияния параметров спектрального анализа на точность распознавания музыкальных жанров.
- **Параметры:** протестировали 3 различных значения длины шага (hop_length) — **512, 1024 и 2048**.
- **Архитектура:** использовали полносвязную нейронную сеть с применением слоев **BatchNormalization** и **Dropout** для стабилизации обучения.
- **Результат:** на основе показателя **val_accuracy** определили, что изменение шага дискретизации напрямую влияет на детализацию признаков и итоговую точность классификации.

### 2. Распознавание команд и цифр (Pro)
Реализовали систему распознавания коротких речевых команд (цифры от 0 до 9), используя аудиобазу.
- **Обработка данных:** извлекли коэффициенты **MFCC** (мел-кепстральные коэффициенты) для представления звука в виде цифровых признаков.
- **Задача:** оптимизировать нейросеть для достижения точности **не ниже 90%** на проверочной выборке.
- **Результат:** подобранная архитектура успешно справляется с классификацией голоса, преодолевая целевой порог точности.

### 3. Распознавание исполнителей (Ultra Pro)
Создали сложную модель для идентификации конкретных музыкальных исполнителей на расширенной аудиобазе.
- **Методы:** реализовали автоматизированную генерацию обучающей выборки с помощью циклов; применили нормализацию данных для выравнивания громкости и частотных характеристик.
- **Параметры:** проверочная выборка составила **10%** от общего объема данных; оценивали точность распознавания для каждого отдельного артиста.
- **Результат:** модель демонстрирует высокую селективность, достигая точности **не ниже 80%** при распознавании уникальных характеристик голоса и стиля исполнения.
